# Новые языки программирования

Индивидуальная работа по курсу «Новые языки программирования».

**20 программ · 20 языков · 5 тем**

Каждой теме отведена отдельная папка с четырьмя заданиями на разных языках. Для каждого задания предусмотрен видеообзор с объяснением задачи, запуском и разбором кода.

| Тема | Папка | Языки |
| --- | --- | --- |
| 1. Многопоточность | `1_threads/` | Rust, D, Julia, Ada |
| 2. Алгоритмические задачи | `2_algorithms/` | Haskell, Scheme, OCaml, Prolog |
| 3. Ввод/вывод в консоль и файл | `3_io/` | Lua, Perl, Odin, Scala |
| 4. Клиент-серверное взаимодействие | `4_client_server/` | Erlang, Elixir, Kotlin, Nim |
| 5. Конвертация данных из одного формата в другой | `5_convert/` | Ruby, Groovy, F#, Swift |

## Тема 1. Многопоточность

Папка: `1_threads/`

**1.1. Продажа билетов из нескольких касс (Rust).** Четыре кассы одновременно пытаются продать 20 билетов: каждая выполняет по 10 попыток. Проверка наличия билета и уменьшение остатка выполняются под одной блокировкой. Главный поток дожидается касс и выводит продажи, отказы и остаток.

**1.2. Параллельная гистограмма оценок (D).** Массив оценок от 0 до 9 делится на четыре непересекающихся блока. Каждый поток считает собственные десять частот. После завершения потоков главный поток складывает локальные гистограммы и сравнивает результат с последовательным подсчётом.

**1.3. Вычисление интеграла в нескольких потоках (Julia).** Вычислить интеграл x² на [0; 1] методом средних прямоугольников. Разбить n прямоугольников на блоки, посчитать суммы блоков параллельно и объединить их. Сравнить с последовательным методом и точным значением 1/3.

**1.4. Парковка с ограниченным числом мест (Ada).** Шесть задач-машин по два раза въезжают на парковку с тремя местами и выезжают. Защищённый объект хранит число занятых мест; вход через entry разрешён, только когда есть свободное место. Итог содержит число завершённых посещений и максимальную занятость.

## Тема 2. Алгоритмические задачи

Папка: `2_algorithms/`

**2.1. Сортировка слиянием с показом разбиений (Haskell).** Рекурсивно разделить список целых чисел пополам, отсортировать половины и слить их собственным алгоритмом. Для короткого примера вывести основные разбиения, исходный и отсортированный списки.

**2.2. Ханойская башня с проверкой числа ходов (Scheme).** Перенести n дисков со стержня A на C через B и вывести последовательность ходов. Рекурсивно перенести n−1 дисков, переместить большой диск, затем перенести n−1 дисков на целевой стержень.

**2.3. Минимальная сдача динамическим программированием (OCaml).** Найти минимальное число монет для заданной суммы и восстановить набор монет. Заполнить таблицу лучших решений от 0 до суммы, запоминая последнюю выбранную монету. Номиналы можно использовать неограниченно.

**2.4. Подбор набора чисел с заданной суммой (Prolog).** Перечислить подмножества списка различных положительных чисел, сумма которых равна цели. Для очередного числа рекурсивно рассмотреть включение и пропуск, затем получить следующие решения через backtracking.

## Тема 3. Ввод/вывод в консоль и файл

Папка: `3_io/`

**3.1. Журнал результатов лабораторных работ (Lua).** Консольная программа принимает имя и оценку 0..100, дописывает запись в TSV-файл, показывает сохранённые записи и среднюю оценку. При следующем запуске данные перечитываются; ошибки ввода объясняются пользователю.

**3.2. Извлечение пронумерованного фрагмента файла (Perl).** Запросить путь к UTF-8 файлу и диапазон строк. Читать файл последовательно, показать выбранные строки с исходными номерами и сохранить тот же фрагмент в отдельный файл отчёта.

**3.3. Побайтовое сравнение двух файлов (Odin).** Прочитать два небольших файла как массивы байтов, сравнить их длины и содержимое. Вывести число различающихся позиций и смещение первого отличия, затем записать текстовый отчёт.

**3.4. Отчёт по измерениям из текстового файла (Scala).** Прочитать UTF-8 файл, где каждая непустая строка содержит одно число. Запросить порог с консоли, вычислить число измерений, минимум, максимум, среднее и количество значений выше порога. Показать отчёт и записать его в файл.

## Тема 4. Клиент-серверное взаимодействие

Папка: `4_client_server/`

**4.1. Сетевая электронная очередь (Erlang).** Сервер выдаёт последовательные номера талонов и хранит FIFO-очередь. Собственный клиент отправляет TAKE, NEXT, STATUS и QUIT. Обработчики TCP-соединений обращаются сообщениями к одному процессу, который владеет состоянием очереди.

**4.2. Бронирование мест в учебном зале (Elixir).** Сервер хранит пять мест, доступных для бронирования. Собственный клиент отправляет LIST, RESERVE номер, RELEASE номер и QUIT. GenServer последовательно обрабатывает изменения, не позволяя двум подключениям забронировать одно место.

**4.3. TCP-сервис перевода единиц измерения (Kotlin).** Собственный консольный клиент передаёт команду и число; сервер возвращает вычисленное значение. Поддержать C_TO_F, F_TO_C, KM_TO_MI, MI_TO_KM и QUIT. Клиент и сервер — два отдельных процесса на Kotlin/JVM.

**4.4. Сетевой словарь терминов программирования (Nim).** Сервер хранит небольшой неизменяемый словарь терминов. Собственный клиент отправляет LOOKUP термин, LIST или QUIT и печатает ответ. Словарь находится только у сервера, поэтому ответ действительно приходит по сети.

## Тема 5. Конвертация данных из одного формата в другой

Папка: `5_convert/`

**5.1. Цветное PPM-изображение в серое PGM (Ruby).** Разобрать текстовый PPM формата P3, прочитать RGB-тройки и записать текстовый PGM формата P2. Использовать учебную формулу серого (R+G+B)/3 с округлением до ближайшего целого. Размер изображения и максимальное значение сохраняются.

**5.2. Журнал JSON Lines в JSON-массив (Groovy).** Прочитать журнал, где каждая непустая строка является отдельным JSON-объектом. Проверить строки, сохранить порядок записей и сформировать один корректный JSON-массив. Ошибка содержит номер исходной строки.

**5.3. Таблица TSV в XML-каталог (F#).** Прочитать таблицу с заголовком id, name, category и тремя полями в каждой строке. Сформировать XML: корень catalog, элементы item с атрибутом id и вложенными name/category. Строки данных преобразуются по явно заданной схеме.

**5.4. JSON-каталог в HTML-таблицу (Swift).** Прочитать JSON-массив объектов с полями name и quantity. Проверить схему, сформировать самостоятельную HTML-страницу с таблицей и сохранить файл, который можно открыть в браузере.
